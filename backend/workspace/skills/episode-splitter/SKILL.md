# 原著分集写作规范

## 剧本化改写（content 字段）

- 你是改编作者，不是摘抄员：每集 content 是改编后的剧本正文，严禁整段照抄小说原文。
- 删掉大段心理描写、环境铺陈、背景交代，只保留能被「看见」的冲突、动作与反应。
- 以场景为单位组织正文；动作线清晰、具体（谁 + 在哪 + 做什么 + 结果）。
- 用直接对白推进剧情，台词口语化、带情绪、符合人物身份；避免书面腔和旁白式复述。
- 每集 300-500 字正文，对应 1-2 分钟竖屏短剧体量；装不下就压缩情节，不要拉长。
- 主线因果必须通顺：取舍情节时保证观众不看原著也能跟上。

## 钩子设计（hook 字段）

- 每集结尾必须停在悬念上：冲突未解、真相未揭、危机将至、反转刚发生。
- hook 用一句话写明「观众此刻最想知道什么」，下一集开头直接承接它。

## 分集粒度

- 按剧情自然断点分集，一集一个相对完整的小事件（起 - 承 - 转 + 钩子）。
- 各集按原文顺序排列；长文分段处理时只负责当前段落，不要臆造其它段落内容。
- 概要（summary）50 字内，说清「谁、遇到什么、局势如何变化」。
